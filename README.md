1. ความหมายของเทคโนโลยีคืออะไร
เทคโนโลยีหมายถึง สิ่งที่มนุษย์ พัฒนาขึ้นเพื่อแบ่งเบาภาระช่วยหรือแก้ปัญหาต่างๆได้ง่ายขึ้น มันสามารถเป็นอุปรณ์, เครื่องมือ, เครื่องจักรและวัสดุ
Linkที่นำมาประกอบ: https://kru-it.com/meaning-of-technology/

2. ความหมายของนวัตกรรม(innovation framework) คืออะไร

นวัตกรรม คิอ แนวคิด วิธีการ หรือสิ่งประดิษฐ์ใหม่ๆ ที่เกิดจากการใช้ความรู้และความคิดสร้างสรรค์ แล้วถูกนำมาใช้งานจริงจนสามารถสร้างคุณค่าและเกิดประโยชน์ต่อเศรษฐกิจ สังคม หรือองค์กร

innvoation framwork หรือกรอบนวิตกรรมคือ ระบบที่มีโครงสร้างที่ชี้นำให้กระบวนการนวัตกรรมทั้งหมดภายในบริษัท โดยจะกำหนดขั้นตอนและวิธีการที่จำเป็นในการพัฒนา ประเมิน และนำแนวคิดใหม่ๆ ไปใช้ เพื่อให้มั่นใจว่าสอดคล้องกับเป้าหมายเชิงกลยุทธ์ขององค์กร กรอบนี้ทำหน้าที่เป็นพิมพ์เขียวสำหรับวิธีการที่บริษัทใช้ในการดำเนินงานด้านนวัตกรรม 
Linkที่นำมาใช้หาความหมายกรอบนวิตกรรม: https://qmarkets.net/resources/article/innovation-framework/

3. ความหมายของ Design Thinking คืออะไร
Design Thinking หรือ การคิดเชิงออกแบบคือ กระบวนการคิดเชิงออกแบบที่เน้นการแก้ไขปัญหาและพัฒานวัตกรรมโดยมีมนุษย์หรือเรียกว่าาผู็ใช้มาเป็นศูนย์กลาง เป็นการผสานความคิดสร้างสรรค์เข้ากับตรรกะทางธุรกิจเพื่อค้นหาทางออกที่เหมาะสมเป็นระบบและตอบโจทย์ความต้องการที่แท้จริง เพื่อผลลัพธ์ที่มีประสิทธิภาพสูงสุด
Linkที่นำมาประกอบ: https://property.jll.co.th/blog/article/what-is-design-thinking
